# 情報源プロファイル: 日本 (JPN)

**この順に当たる。** 公式(official) > 報道(media) > 確認中(tbc) のティアを厳守する。

---

## 1. 消防庁 (FDMA) — 主たる公式情報源

**1日に複数報出る。必ず最新報を探す。**

- 直リンク: `https://www.fdma.go.jp/disaster/info/items/<YYYYMMDD><災害名ローマ字><N>.pdf`
- 一覧: https://www.fdma.go.jp/disaster/info/ — **キャッシュで古い報しか見えないことがある**

### 最新報の探し方

既知の最新Nから `N+1, N+2, …` と試す。**404でも欠番・一時404がありうるので、404の先も最低10番号追う。**
実際にPDFが取得できた最大の番号が最新報。

| 手段 | 可否 |
|------|------|
| サンドボックスからの `curl` / `wget` | ✗ 不可 |
| `web_fetch` | ✗ provenance制約（"URL not in provenance set"） |
| **Claude in Chrome の `navigate` + `get_page_text`** | ✓ **これで存在確認する** |

404なら消防庁のナビゲーションテキストが返り、実在するPDFなら `No text content found` エラーになるので判別できる。
`browser_batch` で複数番号をまとめて確認する。実在が確認できたら `pdftoppm -r 150 -png` で画像化しReadツールで読む。
それも不可ならユーザーにPDF添付を依頼する。

**「最新報が未公表」も正しい結果**。その場合は前報のままである旨をレポート本文（時系列に1行追加）とメールに明記する。

### 抽出項目

死者（市町村内訳・調査中）／行方不明／重傷・軽傷／住家（全壊・半壊・一部破損）／火災／
避難指示・緊急安全確保（世帯・人数）／救助件数／緊急消防援助隊／救助・救急搬送累計

> ⚠️ **「一部破損」と「避難指示世帯数」を取り違えない。**

## 2. 都道府県 被害情報 — 更新が速く、市町村別まで取れる

例: 熊本県 https://www.pref.kumamoto.jp/soshiki/222/276831.html

**1日2回（朝8時ごろ／14時ごろ）更新され、テキスト抽出可能で市町村別の表まで取れる**ので効率がよい。
消防庁より新しいことが多い。人的被害・住家被害（分類未確定を含む）・避難所・避難者の市町別内訳。

### 都道府県 災害対策本部会議

例: 熊本県 https://www.pref.kumamoto.jp/soshiki/222/274487.html

各部報告資料に断水・給水所・ボランティア・応援職員・熱中症搬送・商工業・農林水産被害・ホテル避難。
**会議資料の掲載は半日〜1日遅れることがある。**

## 3. 内閣府（防災）— 全省庁の対応が集約されていて効率的

https://www.bousai.go.jp/updates/ 配下の当該災害ページ

## 4. 気象庁 (JMA)

余震回数・津波・震度改訂。**地方気象台**は今後の気象の見通し。

## 5. 地震調査委員会 (HERP)

評価PDFはテキスト抽出可能。震源断層の長さ・区間・GNSS/InSAR等を `d.fault` へ。

## 6. 官邸

https://www.kantei.go.jp/jp/kikikanri/ 配下 — 非常災害対策本部会議の締めくくり発言

## 7. 国土交通省 地方整備局

例: 九州地方整備局 https://www.qsr.mlit.go.jp/
「対応状況 第N報」PDFに TEC-FORCE の派遣規模・リエゾン・災害対策用機械・断水戸数・道路・港湾・河川。

> ⚠️ 本文で報番号を引用している箇所（表の列見出し `as_of`、注記枠 `note_en/ja`、
> ハードコードされたリンク集のラベルとURL）を**すべて同じ報に揃える**。

## 8. 防衛省

派遣規模の推移。

## 9. 報道（NHK 等）

新規被害を `d.damage_highlights[]` と `d.timeline[]` に**行を追加**する。ティアは media。
