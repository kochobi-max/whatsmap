# _state

定期タスクをまたいで残しておきたい、ごく小さな控え。

定期タスクは**毎回まっさらなセッションで `main` を clone して始まる。**
前回の実行の記憶は何も残らない。「昨日これを知らせた」を覚えておく場所が要る。

| ファイル | 書く人 | 中身 |
|---|---|---|
| `pc_health.json` | `check_pc_health.js --record` | 配布用PCの停止を最後に知らせた日と、そのときの空き日数 |

**送信タスクは、これを必ずコミットしてプッシュする。**
押し忘れると翌朝また同じ通知が出る。

警告メールの送信履歴はここではなく、`events/<GLIDE>.json` の `_warned` に入る
（`warning_gate.js --record` が書く）。イベントJSONと一緒にコミットされる。
