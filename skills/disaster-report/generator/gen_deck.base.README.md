# gen_deck.base.js — 素の権威版（パッチ未適用）

OneDrive の `_kumamoto_generator/gen_deck.js` と同じ内容の、**パッチを1本も当てていない**
状態のコピー。2,165行。`FONT = "Meiryo"`・`LANG_OUT`・`SPLIT_OVERRIDE` を持つ方が権威版で、
`~/.claude/skills/synced/kumamoto-eq-report/` 側の古いコピーではない。

## 何のために置いてあるか

クラウドの定期タスクが**自分でビルドできるようにするため**。
これが無いと、クラウド側は「イベントJSONを直すことはできるが、レポートは作れない」状態になる。

## 直接編集しないこと

このファイルは**素のまま保つ**。改修は `scripts/apply_*.js` のパッチ側に書く。
ここを直接いじると、OneDrive 側の権威版との差が追えなくなる。

ビルドは常に `scripts/build_event.sh` から行う。あれは毎回このファイルを一時ディレクトリに
コピーしてからパッチを当てるので、このファイル自体は変更されない。

## OneDrive 側を更新したとき

権威版に手を入れたら、**素の状態のものをここへ上書きコピーする**。
パッチ適用後のものを置かないこと（次に `apply_all.js` を当てると二重適用の判定に入る）。
