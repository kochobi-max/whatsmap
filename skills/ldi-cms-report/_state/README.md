# _state

定期タスクをまたいで残す控え。**定期タスクは毎回まっさらなセッションで始まる**ので、
「前回これを使った」を覚えておく場所が要る。

| ファイル | 書く人 | 中身 |
|---|---|---|
| `ldi_seen.json` | `scripts/ldi_state.py --record` | Keyごとの前回の判定と、使った記事のURL |

**定期タスクは、これをコミットしてプッシュする。**押し忘れると翌朝また同じ記事を読み直す。

**この台帳は Step 3.5 の代わりではない。** LDI個別ページの確認は毎回・全Key・省略不可。
省けるのは「同じ一次情報源の記事を二度読むこと」だけである。
