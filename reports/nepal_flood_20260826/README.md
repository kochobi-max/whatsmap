# ネパール・ボテコシ／トリスリ川洪水（2026年8月26日）技術検討メモ

氷河起因の土石流・洪水災害に対して、日本の技術で実行可能な防災支援策を検討したメモ。

- 成果物: `index.html`（単一ファイル、外部依存はGoogle Fontsのみ）
- 作成日: 2026-08-29（捜索継続中・数値は暫定）

## 中心的な論点

死者の郡別分布（NDRRMA, 2026-08-29）を洪水波の到達順に並べると、
源頭に最も近いラスワ郡13名に対し、約170km下流のチトワン郡が246名と最多になる。
SMS警報は09:15に67万件配信されており、チトワンへの洪水到達は15:20だった。

したがって中心的な失敗は「危険を検知できなかったこと」ではなく
「手に入れた時間を避難に変換できなかったこと」にある可能性が高い。

ただし郡別数値は**収容遺体数**であり死亡地点ではないため、
検証調査（メモ中のA-0）を全施策に先行させる構成としている。

## 対策の構成

| 群 | 内容 |
|---|---|
| A（即効・1年） | 検証調査、洪水波到達時刻予測、危機管理型水位計＋欠測=警報ロジック、警報範囲の拡張、坑内労働者・外国人プロトコル |
| B（中期・2年） | 源頭マスムーブメント即時検知（地震計・インフラサウンド）、自動サイレン、天然ダム緊急対応の制度移転、越境上流の衛星監視 |
| C（構造物・3〜10年） | 集落単位の高台避難場所、土地利用誘導、水力発電所のEWSノード化 |

## 留意

公開情報に基づく検討であり、関係機関の公式見解ではない。
出典は `index.html` 末尾に一覧。政策判断に用いる前に一次資料での再確認を要する。

## ファイル

- `index.html` — 検討メモ本文（読み物・出典付き）
- `concept.html` — 構想図（1枚もの・会議掲示用）

構想図は本文と同じ内容を、リードタイム軸で1枚に再構成したもの。
中心の図は「上流ほど猶予が短く自動化が要り、下流ほど時間があるため予測と伝達が効く」
という配置原則を、郡別の収容遺体数と重ねて示している。

### 構想図の仕様

- 版面 1587×1122px ＝ A3横（420×297mm, 96dpi）。ブラウザ幅に応じて縮小表示し、印刷時は等倍でA3横1ページ。
- `concept_A3.pdf` は Chromium で書き出したA3横1ページ版。
- フォントは Google Fonts（Zen Old Mincho / BIZ UDPGothic / Noto Sans JP / IBM Plex Mono）。
  等幅指定にも日本語フォールバックを併記すること。省くと日本語が中国語字形に落ちる。
- レイアウトはヘッドレスChromiumで全要素のオーバーフローを実測して調整している。
  文言を増やす場合は `#board` 内の要素で scrollHeight > clientHeight が出ないか再確認すること。

### 書き出し

- `concept_A3.png` — A3横 300dpi（4961×3507px、pHYs付き）
- `concept_A3.pdf` — A3横1ページ

書き出し時は Google Fonts がヘッドレスChromiumから届かないため、
npm の `@fontsource/{zen-old-mincho,biz-udpgothic,noto-sans-jp,ibm-plex-mono}` を
ローカルCSSとして差し替えたコピーをレンダリングすること。
これを省くとコンテナ既定の中国語フォントで描画される。
