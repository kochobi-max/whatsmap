# ネパール・ボテコシ／トリスリ川洪水（2026年8月26日）技術検討メモ

氷河起因の土石流・洪水災害に対して、日本の技術で実行可能な防災支援策を検討したメモ。

- 成果物: `index.html`（単一ファイル、外部依存はGoogle Fontsのみ）
- 作成日: 2026-08-29（捜索継続中・数値は暫定）

## 中心的な論点

死者の郡別分布（NDRRMA, 2026-08-29）を洪水波の到達順に並べると、
源頭に最も近いラスワ郡13名に対し、約170km下流のチトワン郡が246名と最多になる。
SMS警報は09:15に67万件配信されており、チトワンへの洪水到達は15:20だった。

したがって中心的な失敗は「危険を検知できなかったこと」ではなく
「手に入れた時間を避難に変換できなかったこと」にある可能性が高い。

ただし郡別数値は**収容遺体数**であり死亡地点ではないため、
検証調査（メモ中のA-0）を全施策に先行させる構成としている。

## 対策の構成

| 群 | 内容 |
|---|---|
| A（即効・1年） | 検証調査、洪水波到達時刻予測、危機管理型水位計＋欠測=警報ロジック、警報範囲の拡張、坑内労働者・外国人プロトコル |
| B（中期・2年） | 源頭マスムーブメント即時検知（地震計・インフラサウンド）、自動サイレン、天然ダム緊急対応の制度移転、越境上流の衛星監視 |
| C（構造物・3〜10年） | 集落単位の高台避難場所、土地利用誘導、水力発電所のEWSノード化 |

## 留意

公開情報に基づく検討であり、関係機関の公式見解ではない。
出典は `index.html` 末尾に一覧。政策判断に用いる前に一次資料での再確認を要する。

## ファイル

- `index.html` — 検討メモ本文（読み物・出典付き）
- `concept.html` — 構想図（1枚もの・会議掲示用）

構想図は本文と同じ内容を、リードタイム軸で1枚に再構成したもの。
中心の図は「上流ほど猶予が短く自動化が要り、下流ほど時間があるため予測と伝達が効く」
という配置原則を、郡別の収容遺体数と重ねて示している。

### 構想図の仕様

- 版面 1587×1122px ＝ A3横（420×297mm, 96dpi）。ブラウザ幅に応じて縮小表示し、印刷時は等倍でA3横1ページ。
- `concept_A3.pdf` は Chromium で書き出したA3横1ページ版。
- フォントは Google Fonts（Zen Old Mincho / BIZ UDPGothic / Noto Sans JP / IBM Plex Mono）。
  等幅指定にも日本語フォールバックを併記すること。省くと日本語が中国語字形に落ちる。
- レイアウトはヘッドレスChromiumで全要素のオーバーフローを実測して調整している。
  文言を増やす場合は `#board` 内の要素で scrollHeight > clientHeight が出ないか再確認すること。

### 書き出し

- `concept_A3.png` — A3横 300dpi（4961×3507px、pHYs付き）
- `concept_A3.pdf` — A3横1ページ

書き出し時は Google Fonts がヘッドレスChromiumから届かないため、
npm の `@fontsource/{zen-old-mincho,biz-udpgothic,noto-sans-jp,ibm-plex-mono}` を
ローカルCSSとして差し替えたコピーをレンダリングすること。
これを省くとコンテナ既定の中国語フォントで描画される。

## EWS構造図（`ews.html`）

統合EWSの5層アーキテクチャをA3横1枚に示したもの。構想図（`concept.html`）とは別建て。

**主張は「新設ではなく改良」**。ネパールは既に広帯域地震計約40局・加速度計約36台を持ち、
東京大学とJICAは既に8局を設置済み。不足しているのは地震計ではなく、
その信号を質量移動と洪水として読む処理系と、警報に変える制度である。

図の色分けがこの主張を担っている。

| 色 | 意味 |
|---|---|
| 灰 | 既存をそのまま使う |
| 赤枠 | 既存だが今回機能しなかった |
| 青緑 | 既存を改修する |
| 青 | 新規に足す |

恒久設備の新設は L1 の3項目と L2 の衛星IoT のみ。残りはソフトウェアと制度にあたる。

出力は `ews_A3.png`（300dpi）と `ews_A3.pdf`。再生成手順は上記と同じ
（`@fontsource` のローカルCSSに差し替えてからレンダリング）。

## 英語版（`concept_en.html` / `ews_en.html`）

構想図とEWS構造図の英語版。内容・配色・グリッドは日本語版と同一で、
書体だけを IBM Plex Serif（見出し）／IBM Plex Sans（本文）／IBM Plex Mono（数値・ラベル）の
1スーパーファミリーに差し替えている。日本語フォントの参照は残していない。

構造図のバッジは日本語版の 既／改／新 に対して **E（existing）／M（modified）／N（new）** を用いる。

### 英語版で必要になった調整

英字は同じ級数でも日本語より字面が横に広く、初回組版では
`ews_en.html` で8要素、`concept_en.html` で14要素がクリップされた。
そのため両ファイルとも `<style>` の末尾に英語版専用の級数調整ブロックを置いている
（`.cx p` `.kv dd small` `.gs` 等を 0.2〜1.0px 下げる）。

`concept_en.html` の中心図は幅固定のSVGボックスを持つため、
7つの施策ボックスを「見出し／表題／説明2行／出典1行」の5行構成に組み直した
（日本語版は4行）。ボックス内の各 `<text>` がボックス右端を越えていないかは
`getBBox()` で実測して確認している。

### 書き出し

- `concept_en_A3.png` / `ews_en_A3.png` — A3横 300dpi（4961×3507px、pHYs付き）
- `concept_en_A3.pdf` / `ews_en_A3.pdf` — A3横1ページ

英語版は `@fontsource/{ibm-plex-serif,ibm-plex-sans,ibm-plex-mono}` を
ローカルCSSに差し替えたコピーをレンダリングする。

## 2026-08-31 改訂

被害数と源頭機構の両方が動いたため、日英4枚すべてを更新した。

### 被害数（NDRRMA 2026-08-31 09:00 NPT）

死者 903名・不明 4,247名（うち外国人592名）・負傷 1,473名・救助 10,451名。
チベット側は死者16名・不明546名。郡別は
チトワン272／ナワルパラシ東207／同西151／ヌワコット95／ゴルカ62／ダディン55／タナフン37／ラスワ24。

図の初版（8/29 18:30・675名）からの増加228名は下流に偏るが、
8/30から8/31にかけては上流も伸びた（ラスワ13→24、ヌワコット51→95）。
**収容はアクセス回復に律速される**という図中の留保が、そのまま観察された形である。
分布の骨格は変わらず、警報対象外4郡が50.6%、最下流3郡だけで69.8%、最上流のラスワは2.7%。

### 源頭機構 ── 第4版で収束

図の初版は第3版（「持続的な堰止めの証拠なし」）で止まっていた。第4版は両者の中間にあたる。

- 源頭は**ランタン・リルン北面**、Chhochen Khola 上部（ネパール側）。幅約610m・面積0.2km²の氷体が約1,200m落下
- 氷岩なだれが**レンデ川を短時間閉塞**し、決壊して単一のサージとして放出された（ICIMOD／USGS）
- USGS は当初の信号を地震ではなく崩壊由来と確認、GFZ は単一力／セントロイド力モデルで **Mw 5.7**

これに伴い、B-3（河道閉塞の緊急評価）の但し書き「今回は不成立の可能性」を削除した。
閉塞は初期機構の一部であり、かつ 8/28 には Chhochen Khola × Purepu Tsangpo 合流点に
堰止湖（約200万m³）が形成されて越流・決壊し、捜索を中断させている（8/30時点でほぼ空）。

### 実測で裏づけられた数値

| 図の記載 | 実測・推定 |
|---|---|
| 超過分 10⁷ m³ | デブガット通過の超過量 **約2×10⁷ m³** ── 桁が一致 |
| ピーク水位 6.57m | **ピーク流量 5,850 m³/s**（洪水予報課） |
| 幅約600m・1,200m滑落 | 幅610m・面積0.2km²・1,200m落下 |

氷体 0.2km² は厚さ30〜60mなら 10⁷ m³ 台で、**超過水量と同オーダー**。
「摩擦融解では氷質量の3.5%が上限」という制約と合わせると、
水は湛水分＋巻き込んだ河川水＋バルキングで説明するほかない。図の中心的な物理論点は維持している。

## 2026-09-03 改訂

### 被害数（NDRRMA）

全国で死者 1,114名・不明 約4,500名（チベット側は死者16名・不明546名）。救助約12,000名、
影響人口 約160万人。2015年のゴルカ地震以来、ネパール最悪の災害となった。

郡別（9/1 09:00、回廊8郡 計987名）は
チトワン321／ナワルパラシ東216／同西170／ヌワコット95／ゴルカ65／ダディン55／タナフン38／ラスワ27。

**全国計と回廊計を混ぜないこと。** 全国の1,114名には回廊外の死者が含まれ、
不明者が「62郡から報告されている」のは被災者の出身地が全国に散っているためで、
被災地が62郡あるという意味ではない。図の棒グラフは回廊8郡のみを扱い、その旨を注記した。

警報対象外だった4郡は 489/987＝**回廊の49.5%**、最下流3郡だけで71.6%、最上流のラスワは2.7%。

### 源頭機構の訂正

Cook・Shugar らの衛星・ドローン画像解析により、**基盤岩が氷とともに崩壊した**ことが確認された。
8/31改訂で「氷体が崩落」と書いたのは弱い記述であり、初版の「基盤岩ごと崩壊」に戻した。

### 水収支 ── 結論を強める方向で訂正

EGU 水文科学部門（8/28）の暫定推定で、**初期崩落体積は 0.5〜10×10⁶ m³**。
これはデブガット通過の超過水量（約2×10⁷ m³）**より小さい**。
8/31改訂では「氷体と超過水量は同オーダー」と書いたが、これは過大評価だった。
**水の大半は流下途中に得たもの**（河川水の巻き込みとバルキング）と考えるほかなく、
図の記述をその趣旨に改めた。摩擦融解が氷質量の3.5%を上限とする制約は変わらない。

### 新知見の反映 ── Zhong, Allen, Li et al. (2025), Landslides 22:989–1001

ヒマラヤの大規模岩氷なだれ60件（死者計1,366名以上）の解析から、
L0（平時のリスク評価）に使える判定基準が得られた。

- 86% が **傾斜30°超・標高3,000m超**で発生
- 65% が**永久凍土が存在すると推定される場所**で発生
- 約半数が**連鎖災害**に発展し、単発事象に比べ**死者は約10倍**
- 発生体積 10⁶〜10⁸ m³ が最も連鎖しやすく、**大河川の近くで連鎖確率が有意に上がる**

本件はこの「最も連鎖しやすい」区分にそのまま該当する。
L0を「曝露の把握」から「崩壊源のスクリーニング」に変え、上記4条件を判定基準として採用した。

### 越境の位置づけを再定義

ICIMOD は「**崩壊がネパール側で始まったため、中国側のEWSの対象外だった**」と述べている。
これはデータ共有の不足ではなく、**自国で検知するほかない**という問題である。
B-1（地震学的検知）の根拠がこれで一段強くなった。図の該当箇所を書き換えた。

### 坑内労働者 ── 具体化

被災した12の水力発電所で**約900名が行方不明、うち約500名が坑内**と見られる。
アッパー・トリスリ1だけで576名が不明、うち約300名が坑内。泥に埋まった3本の坑道から4遺体を収容。
坑道は数km に及び、生存可能性はあるが空気の供給が制約になる。
GAP 4・A-4・L5（坑内一斉警報）・C-3（発電所のEWSノード化）の根拠を、この数字に差し替えた。

### 前兆について ── 記述は変えていない

崩壊2日前に地表温度の異常が記録されていたとの報告があるが、**事後に見つけたもの**である。
チャモリ2021の2.5時間前の前兆と同じ扱いとし、「予知はしない」という設計前提は維持した。
両者を並べて「研究としては重要だが設計の前提には置けない」と明記している。
