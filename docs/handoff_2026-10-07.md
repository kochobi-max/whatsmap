- **LDI の定期タスクは Cowork 環境（`env_011111111111111111111117`）で動き、シェルは外へ一切出られない。**
  reliefweb / adrc / gdacs / ndma / globalsign すべて CONNECT 403（確認用セッションで実測）。
  `pdftotext` と `pdfplumber` はある。読むのはブラウザ
- **LDI の Routine はWindowsデスクトップに紐づいている。** プロンプトの変更は `update_trigger` では
  `needs_device_approval` で何も変わらない。PCの Claude デスクトップで手編集。**削除して作り直さない**

  `SendUserFile` → 荒木田さんが「Save skill」→ `~/.claude/skills/synced/*/ldi-cms-report/` と diff。手順は `skills/ldi-cms-report/UPLOAD.md`
- **災害レポートの定期タスクはリポジトリの SKILL.md を読む。** スキルの上げ直しは不要
- **対話用クラウド（Default）からは ReliefWeb を curl で読め、添付PDFも `pdftotext -layout` で州別表まで取れる。**
  ADRC は中間証明書を送らないので `skills/ldi-cms-report/references/certs/` の PEM を `--cacert` に足す（検証は外さない）
